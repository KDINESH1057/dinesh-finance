# Dinesh Finance Pro 2026

Working mobile-first personal finance/PWA starter.

Includes:
- Profile
- Income and bank balance
- Expense tracking
- Rent, fuel, bike service, food, bills, EMI, shopping, travel, entertainment, waste, etc.
- Monthly budget
- Savings goals
- Loan/EMI tracker
- Recurring payment tracker
- Bike fuel + mileage calculator
- Calendar/date filtering
- Waste analysis
- CSV/JSON export
- Print/PDF report
- English/Telugu title toggle
- Local persistence
- PWA manifest/service worker

Open index.html to run locally. PWA installation generally requires HTTPS hosting (or localhost). Cloud login/sync and native APK signing require a backend/build environment and are not included in this offline package.
